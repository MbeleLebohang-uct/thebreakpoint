# 🏡 The Breakpoint

A beautiful guest house in Beaufort West, Western Cape, South Africa. Built with Next.js 15, TypeScript, and Tailwind CSS.

## ✨ Features

- **Responsive Design**: Beautiful, modern UI optimized for all devices
- **Villa Showcases**: Detailed pages for each room with galleries
- **Location Information**: Interactive content about the Beaufort West area
- **Contact System**: Easy inquiry forms for bookings
- **SEO Optimized**: Built-in sitemap and robots.txt
- **Performance**: Fast loading with Next.js 15 and Turbopack

## 🛠️ Tech Stack

- **Framework**: Next.js 15.2.1 with App Router
- **Language**: TypeScript
- **Styling**: Tailwind CSS v4
- **UI Components**: Radix UI primitives
- **Forms**: React Hook Form with Zod validation
- **Icons**: Lucide React
- **Development**: ESLint, Prettier


## 🚀 Getting Started

### Prerequisites

- Node.js 18+
- pnpm (recommended) or npm

### Installation

1. Clone the repository:

```bash
git clone <repository-url>
cd thebreakpoint
```

2. Install dependencies:

```bash
pnpm install
```

3. Start the development server:

```bash
pnpm dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

## 📝 Available Scripts

- `pnpm dev` - Start development server with Turbopack
- `pnpm build` - Build for production
- `pnpm start` - Start production server
- `pnpm lint` - Run ESLint
- `pnpm format` - Format code with Prettier
- `pnpm format:check` - Check code formatting

## 🎨 Design System

The project follows a consistent design system with:

- **Naming Convention**: kebab-case for component files, PascalCase for exports
- **Styling**: Tailwind CSS with custom brand colors
- **Components**: Modular, reusable components in `/components/ui/`
- **Responsive**: Mobile-first responsive design
